# Журнал изменений

Все заметные изменения проекта фиксируются в этом файле.

## [0.0.1] — 2026-08-16

### Добавлено
- Сервер ASP.NET Core + SignalR (`ChatServer`) вместо WCF `ChatHost` и duplex-сервиса на `netTcpBinding`.
- Хаб HTTP/WebSocket `/chat` с прежней логикой: поиск собеседника, сообщения, рукопожатие протокола и ретрансляция голоса.
- Подключение десктоп-клиента через SignalR (`ChatHubClient`) вместо WCF callback-канала.
- Проверка живости `GET /health` и Dockerfile для размещения на Linux.

### Изменено
- Транспорт чата — WebSocket на `http://localhost:5000` (адрес задаётся в `ChatClient/App.config`).
- Клиент по-прежнему WPF-приложение под Windows; сменился только протокол сервера.

### Примечания
- Старые WCF-проекты (`WCF_Chat`, `ChatHost`) оставлены в репозитории для справки и в работе не используются.
